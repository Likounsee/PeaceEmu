The philosophy

Built to be understood.
Designed to evolve.

Emulation is a complex engineering challenge. PeaceEmu aims to approach it with a modular structure, maintainable code and an open development process.

Modular by design

A project structure built around separate components and emulation cores, helping keep responsibilities clear as the codebase develops.

Built primarily with Rust

Leveraging Rust's type system and memory-safety features to support a codebase that can be tested, maintained and extended.

Open development

Source code, issues and development progress are available through GitHub. Follow the project and see how it evolves.

Under the hood

A foundation for multiple systems.

The goal is to give individual emulation components a place within a shared project, rather than treating every system as an entirely separate application.

Architecture concept

One project. Separate components.

A shared application layer can provide common functionality, while individual cores handle the specific logic required by each target system.

Designed around separation of responsibilities.
Intended to support independent development and testing.

Development status

An open-source emulator framework in Rust.

PeaceEmu is an early-stage, multi-console emulation project. Current development focuses on the shared runtime, clear interfaces between emulation cores, input and media contracts, and reproducible tests. The project is built in the open so its progress can be checked directly against the source code.

01

Shared runtime foundations

The Rust workspace includes foundations for system identifiers, core registration, independent session lifecycles, input state, and common media payloads. These building blocks are still being developed and tested.

02

Game Boy core prototype

A limited LR35902 instruction subset can execute simple code from ROM-only cartridges. Video output, audio, timers, interrupts, banking and full instruction coverage are not yet implemented; this prototype is not a claim of playable-game compatibility.

03

Transparent compatibility claims

No console is currently advertised as supported. Compatibility will only be claimed when a real emulation core and reproducible tests demonstrate it. Follow implementation details and the roadmap in the public repository.
